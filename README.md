# Эмблика — сайт студии красоты

Тестовый сайт для показа заказчику: направления и прайс с поиском, о студии, мастера, галерея, обучение, отзывы Яндекса, собственная запись, заявки клиентов и учеников, кабинет администратора.

- Сайт: https://emblema.tw1.ru/
- Кабинет: https://emblema.tw1.ru/admin/
- [Руководство по работе с сайтом](SITE_GUIDE.md) — запуск, база, админка, публикация и ограничения.
- [Инструкции для разработчика и ИИ-агента](AGENTS.md).

Стек: React 19, Vite 7, Astryx, PHP 8.2, SQLite. Фотографии и шрифты локальные. Виджет Яндекса загружается после разрешения посетителя.

## Запуск

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173/. Для каталога, записи и админки отдельно нужен PHP-сервер на порту 8092 — см. руководство.

```sh
npm run build
```

Сборка в `dist/` включает интерфейс, PHP API и кабинет. Она генерируется из исходников и не хранится в Git.

## Демонстрационный режим

Записи сохраняются в базе, но не бронируют реальный визит. Используйте вымышленные данные и тестовый телефон `+7 000 000-00-00`. Расписание и длительности демонстрационные, уведомления студии не отправляются, юридические документы — черновики.

Секреты, база, зависимости и архивы публикации исключены из репозитория. Доступ администратора передаётся отдельно, пароль нельзя помещать в документы, коммиты или переписку.

- [Яндекс Карты](https://yandex.ru/maps/org/emblika/145016511707/) — адрес, контакты, фотографии, ориентиры цен и отзывы.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — рекомендации по дизайну.
- [Astryx](https://github.com/facebook/astryx) — компоненты.

Права на фотографии и актуальность информации подтверждает заказчик перед рабочим запуском. Репозиторий не предоставляет лицензии на сторонние фотографии.
